# Manco v0.5.9 发布总结

## 阶段目标

- 订阅支持启用/禁用（网页菜单、多选胶囊条、TG 指令）。
- 直接下载的作品临时进入订阅清单，下完自动消失；删卡片只清未完成任务、保留已下载文件。
- TG 搜索 → 作品详情 → 返回/订阅 的交互重构。
- 一批界面与默认值调整（排序、筛选栏、滚动条、章数胶囊、下载并发默认值、系统设置布局）。

## 实际改动

### 订阅

- `subscriptions` 新增 `temporary` 列（迁移 + `subscriptionSelect` / `scanSubscription` / `UpsertSubscription` 同步）。
- 详情页「下载」建完任务后，若该作品没有正式订阅，则写一条 `temporary=true`（无 cron）的订阅，卡片立即出现在订阅清单并显示排队/下载中；已有正式订阅时不改动。
- `pruneTemporarySubscriptions` 在每次读取订阅清单前清理：`temporary` 且已无 `queued/running/waiting/paused` 任务时删除卡片，**文件保留**。
- `handleDeleteSubscription`：`cancelUnfinishedJobs` 先 `engine.Cancel` 掉正在下载的任务、删除排队/等待/暂停的任务记录，再删订阅行；已完成记录与本地文件不动。新增 `Store.UnfinishedDownloadJobsByComic`。
- 启停：卡片三点菜单在「补全」后、「归档」前新增 `启用 / 禁用`；多选胶囊条在「刮削」后新增批量 `启用/禁用`（任一为禁用则整体启用，否则整体禁用）；禁用卡片 `opacity .58 + grayscale .85` 置灰；`runBatch` 执行后保留多选状态。
- 订阅清单排序由 `updated_at DESC` 改为 `created_at ASC, id ASC`（按订阅先后，最早→最新），与本地仓库目录胶囊、TG 列表一致。

### TG

- 新增中文指令 `启用 作品名` / `禁用 作品名`；`App` 接口加 `BotSetSubscriptionEnabled`。
- 新增 `Service.registerCommands`，启动后调 `setMyCommands` 注册 `/start`、`/subscriptions`、`/sources`、`/s` 快捷指令（此前完全没注册，客户端不显示命令菜单）。
- 搜索交互重构：新增通用 `callMethod`（返回 `message_id`）与 `deleteMessage`；`resultEntry` 带 `Cover` / `Summary`；点候选后用 `sendPhoto` 发**独立消息**（封面 + 作者 + 最新章节 + 简介），搜索结果原样保留；`返回` 直接删除详情消息；`订阅` 成功后删除搜索结果与详情、清会话，并回复 `《作品名》订阅成功，开始下载到 <下载位置末级目录名>`（封面取不到时自动退回纯文本）。
- 订阅列表序号由数据库主键改为连续序号。

### 下载与任务列表

- 全局同时下载章节数默认 `2 → 10`（全局硬上限，单来源只能更低）；每章图片并发默认 `4 → 2`（内容源配置优先，全局为保底）。
- 任务列表同状态内改为 `id ASC`（排队/下载中按先入先出，与实际执行顺序一致），失败/取消仍 `id DESC`；此前新入队任务显示在列表最前，看起来像插队。

### 界面

- 滚动条悬浮高亮改为品牌橘色 `rgba(224,122,47,.72)`。
- 筛选栏：不再横向滚动、不因下拉展开变形，超出宽度省略，`z-index` 抬升避免被作品网格遮挡。
- 本地仓库章数胶囊背景 `#e07a2f → #f26a12`。
- 模糊封面悬浮卡片时也放大（此前静态模糊规则压掉了动画）。
- 系统设置：TG 通知与下载设置同排（三行布局为「账号+代理 / 下载设置+TG / 归档+关于」），「启用 TG 通知」移入表单栈；关于卡片 `min-height: 280px` 并加橘猫 logo 水印。

## 已知问题

- TG `sendPhoto` 用封面 URL 交给 Telegram 抓取，源站有防盗链时会退回纯文本详情。
- `ImportSubscription`（configstore 启动快照恢复）没有带 `temporary` 列，恢复出来会当成正式订阅；临时卡片本身只在下完前短暂存在，影响可忽略。
- 带筛选（失败/排队/关键词）的任务列表只在已加载的那一页里过滤，筛选条件尚未下推到 SQL。
