# Manco v0.4.6 发布总结

## 阶段目标

- 补齐内置禁漫天堂内容源的筛选分类，使其接近 Kototoro 插件版禁漫天堂。
- 让筛选器实际驱动周榜、分类和标签搜索，而不是只显示选项。

## 实际改动

- 内置禁漫天堂新增「每周必看」「分类」「主题A漫」「角色扮演」「特殊PLAY」「其他」筛选组。
- 分类组补充「禁漫汉化组」；标签组按 Kototoro 禁漫解析器的分组和顺序提供选项。
- 「每周必看」支持直接读取最新一期，分类仍使用站点的分类列表接口。
- 主题、角色、特殊PLAY、其他标签组合后调用禁漫搜索接口，并保留当前排序方式。
- 浏览接口现在会把内容源自己的筛选组参数透传给来源，不再只支持固定几个筛选键。
- 增加筛选组、周榜路由、标签搜索路由和最新周 ID 的回归测试；真实禁漫接口验证通过。
