# Manco v0.8.2 发布总结

## 阶段目标

本次为常规版本，承接 v0.8.1。登录页改为更宽的无边框登录栏，左侧 Bangumi 海报增加可交互圆点胶囊，并放大品牌图标；同时合入上一笔尚未推送的作品来源详情链接和标签悬浮高亮修复。

遵循先推送代码和标签、再补总结的顺序，不移动已有版本标签。

## 实际改动

### 登录页海报与登录栏

- 桌面布局由约 2:1 调整为 62:38，右侧登录区略微加宽。
- 右侧登录栏移除卡片背景、边框、圆角和阴影，直接落在页面面板上。
- 登录图标从 54px 放大到 72px，登录标题左对齐，输入框和登录按钮高度提升到 48px。
- Bangumi 封面移除颜色滤镜，继续优先使用 `images.large` 高分辨率图片。
- 窄屏改为上方 44vh 海报、下方无卡片登录区，避免作品简介覆盖登录表单。

### 海报切换圆点

- 左侧海报右下角新增圆点胶囊条，使用磨砂半透明背景。
- 支持悬停、键盘聚焦和点击切换作品，并重新开始 12 秒轮播计时。
- 当前圆点从 8px 圆点平滑扩展为 22px 横条，切换方向和封面过渡同步。
- 移动端圆点固定在图片右下角，不遮挡下方登录表单。

### 合入的来源详情链接修复

- 插件来源优先保存并解析 Kototoro `publicUrl`，已缓存作品可从编码 ID 恢复直接详情地址。
- 后端补齐神凑、Gutenberg、Z-Library 和自定义绝对 URL 的作品详情路径。
- 作品详情封面下方不再显示原生悬浮文本提示。
- 作者胶囊和 Tag 标签增加淡橘色悬浮与聚焦高亮。
