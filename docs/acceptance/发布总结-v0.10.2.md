# Manco v0.10.2 发布总结

## 阶段目标

补齐作品详情页的章节工具栏与未知元数据提示，在订阅计划第二行增加搜索栏，并展示 Bangumi 条目的章节数量。Bangumi 继续用于作品展示、订阅与订阅历史章节下载，不提供阅读预览。

用户明确要求完成后推送，本次承接 v0.10.1，按常规版本发布 v0.10.2。遵循先推送代码与版本标签、再立即补写总结的顺序，历史标签不移动。

## 实际改动

### 作品详情

- 全选按钮、最新/最旧排序图标按钮和章节数量改为同高圆角框，统一 36px 高、8px 圆角，适配明暗主题。
- 对调排序图片，使图标与当前最新/最旧状态一致，不改变实际章节排序逻辑。
- 保留全选高亮及章节选择功能，补充全选的可访问状态。
- 作者、状态与更新时间缺失时，分别显示未知作者、未知状态、未知更新时间；纯空白状态与无效日期同样回退。
- 章节总数旁也保留未知更新时间提示，有有效数据时仍显示原有作者、状态及日期。

### 订阅搜索

- 在订阅计划第二行右侧、排序筛选器左边增加搜索栏，与父目录选择器和排序控件同为 34px 高。
- 输入后 260ms 防抖搜索，也支持回车立即执行和清除恢复；改变关键词后重置列表位置与选择状态。
- 支持按作品标题、自定义作品目录名、作者搜索，组合当前来源类型、父目录和排序。
- 搜索由 SQLite 在分页前执行，不仅过滤已经加载的首批 60 张卡片，也不将全库卡片拉到浏览器。
- 使用参数化的字面子串匹配，`%`、`_` 不作为 SQL 通配符，英文按 SQLite 既有小写比较方式处理。
- 保留类别总数与目录选项，搜索无结果显示相应提示，不误显示首次订阅空库引导。
- 即使没有父目录记录，也保留搜索与排序；窄屏自然换行，搜索框和排序器不重叠。
- `GET /api/subscriptions` 增加可选 `q`，前端 `api.js` 同步；搜索时未指定页大小则使用既有默认 60 条，明确传入 `limit/offset` 时继续分页。无关键词的原有不分页调用保持不变。
- 新增 Node 参数编码回归，并接入现有 CI。

### Bangumi 章节数

- 复用已有 subject 详情请求与持久缓存，不新增逐章目录或阅读资源请求。
- 按 Bangumi 官方接口定义，将书籍条目的 `eps` 话数映射到已有 `Comic.chapterCount`；缺失或非正数时回退 `total_episodes` 数据库章节数量。
- 不将 `volumes` 册数冒充章节数量；无有效数量时显示章节数未知。
- Bangumi 详情显示只读章节总数，不生成可选择或可下载的章节条目，不展示章节全选、排序或单独下载按钮。
- 预览函数增加 Bangumi 防护，双击数量不触发阅读预览；订阅窗口仍保留历史章节选项，后续实际下载继续由匹配内容源承担。
- 应用版本与 README 标签示例同步为 v0.10.2。
