# Manco v0.8.0 发布总结

## 阶段目标

本次为常规版本，承接 v0.7.9。为登录页增加 Bangumi 近期注目作品背景，同时保持系统代理约束：未配置代理时不请求 Bangumi，也不渲染背景。

上一阶段要求的本地仓库和订阅计划动态滚动范围已经随 v0.7.9 发布。本次不重复修改该逻辑。

遵循先推送代码和标签、再补总结的顺序，不移动已有版本标签。

## 实际改动

### Bangumi 数据接口

- 新增公开接口 `GET /api/login/bangumi`，登录前即可读取背景条目。
- 仅在系统代理非空时请求 Bangumi，并复用内容源注册表中的 HTTP 客户端和代理凭据。
- 读取 Bangumi 日历，今日放送优先，再按想读、收藏和在看数据计算注目顺序。
- 仅保留动画类型且存在封面的作品，最多返回 8 部。
- 并发读取作品详情，补全中文标题、简介和更高分辨率封面，详情并发限制为 4。
- 条目缓存 30 分钟，避免反复请求 Bangumi。
- 作品链接固定生成 Bangumi 条目地址，不使用远端响应中的任意跳转地址。

### Bangumi 封面代理

- 新增公开接口 `GET /api/login/bangumi/cover?subject=<id>`。
- 只允许读取当前条形目中记录的 Bangumi 图片地址。
- 图片域名限制为 `bgm.tv` 及其子域名，HTTP 图片统一升级为 HTTPS。
- 单张封面最大 4 MiB，内存缓存总上限 16 MiB，并清理过期条目。
- 封面响应只接受 `image/*` 内容类型，未配置代理时直接返回 404。

### 登录页背景

- 有有效条目时显示全屏封面、磨砂遮罩、作品标题和最多三行简介。
- 每 12 秒切换一部作品，使用左右滑动和淡入淡出过渡。
- 提前预加载当前和下一张封面，降低切换时的空屏概率。
- 点击作品信息可打开对应 Bangumi 条目页面。
- 无代理、接口失败、标题缺失或没有有效简介时，整个背景图层不渲染。
- 保持原登录卡片布局，并分别适配桌面和窄屏视口。

## 已知限制

- 当前环境没有可用的系统代理凭据，因此未执行真实代理链路的端到端页面验收；代理客户端复用、无代理拦截、域名白名单、响应解析和页面空状态均有测试或独立实例验收覆盖。
