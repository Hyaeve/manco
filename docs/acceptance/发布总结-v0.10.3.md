# Manco v0.10.3 发布总结

## 阶段目标

按用户明确要求，下载作品只维护作品目录里的作品级 `ComicInfo.xml`，Manco 新生成的章节 CBZ 不再内嵌章节级 ComicInfo。正常下载新章节不反复覆盖已有的作品级文件，缺失或损坏时可以修复，手动刮削仍可更新整部作品的信息。

本次承接 v0.10.2，按常规版本发布 v0.10.3。用户已明确要求推送，执行先推送代码与版本标签、再补写总结的流程，不移动历史标签，不批量修改已有下载。

## 实际改动

### 作品级元数据

- 漫画和书籍共用作品级文件保留检查。已有正常 `ComicInfo.xml` 时，下载新章节不改变其内容和修改时间。
- 首次下载、文件缺失、空文件、XML 损坏、标题不匹配或遗留章节级字段时，生成或修复作品级文件。
- 作品级文档直接记录作品名、作者、简介、标签、状态信息、来源标识等，不再由章节文档派生。
- 只缺封面或 series.json 时，不覆盖正常的作品级 XML；过时 OPF/book 侧车继续按原规则清理。
- 手动刮削仍可重新获取并更新作品级文件，写入使用既有临时文件与重命名流程。
- series.json 保留并继续更新已下载数量，不改变项目现有的目录级摘要约定。

### 章节压缩包

- 普通漫画和合并漫画不再生成、暂存或打包章节级 `ComicInfo.xml`。
- 正文书籍、插件图文书籍和合并书籍生成的 CBZ 同样不内嵌 ComicInfo，只包含正文、插图及样式等阅读内容。
- 移除章节 XML 生成函数及仅为该功能传递的章节标题、编号和页数参数。
- 图片条目编号、正文顺序、章节文件名和任务数据库中的章节顺序保持原样。
- 旧断点缓存残留的 ComicInfo 不会被加入新生成的压缩包。
- 作品目录改名不再逐个打开或重写 CBZ；目录级元数据和 EPUB 自身标题仍按既有流程同步。
- 已下载 CBZ 不自动清理或重打包，来源直接提供的原生 CBZ、EPUB 和 PDF 下载内容继续原样保留；视频 NFO 行为不变。
- README 补充新的元数据行为，应用版本和发布示例同步为 v0.10.3。

## 已知限制

- 历史 CBZ 里已有的 ComicInfo 不会自动删除，本次没有对用户现有下载做批量迁移。
- 来源原生电子书可能自带元数据，Manco 不主动剥离或重打包。
- 本地预览和读取接口已验证，不代表已验收所有外部阅读器；外部阅读器是否支持目录级 ComicInfo 取决于其自身能力。
- 未使用真实来源账号或 NAS 下载目录验收，不宣称解决了此前所有章节编号或来源排序异常。
- 未执行 Go race 检测或本地 Docker 构建，镜像交由 GitHub Actions 构建并另行核验。
- 本次无新增 API 或响应结构，未改变前端接口约定、订阅基线、任务状态归属或插件图片处理流程。
