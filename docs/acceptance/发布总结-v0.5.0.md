# Manco v0.5.0 发布总结

## 阶段目标

- 在探索发现进入的作品详情页补充最后更新时间。
- 降低页面滚动条高亮颜色的视觉强度。
- 提高运行日志正文可读性，并减轻日志级别标签背景色。
- 让订阅 cron 到点时同时执行更新检查与失败项检测，失败章节重新获得两轮延时重试预算。
- 完成全量构建测试后，以中文提交信息和标签说明推送 `v0.5.0`。

## 实际改动

### 作品详情页

- 探索发现进入的作品详情页在作者、连载状态之后显示“最后更新”时间。
- 仅当内容源返回 `updatedAt` 时显示，避免为空时留下占位文本。

### 界面细节

- 全站滚动条默认颜色改为更浅的灰色，悬浮高亮降低主色占比，保持淡黄色提示但不再过深。
- 原始运行日志正文提升到 `15px`，结构化日志提升到 `14.5px`，并适当增加行高。
- 日志级别标签改用浅色透明背景和对应彩色文字；深色主题增加单独配色，保持可读性。

### 订阅失败恢复

- 下载引擎新增按“来源 + 作品”重启失败项重试预算的方法。
- cron 表达式到点执行时，先完成例行更新检查，再检测该订阅下的失败或取消章节。
- 检测到的失败项会重新入队，并重新获得两轮延时重试：首次失败后 10 分钟、第二次失败后 30 分钟。
- 订阅卡片的手动“检查更新”继续复用同一重试入口，手动检查与 cron 检查行为一致。

## 已知问题

- cron 重启失败项重试预算不会修改下载引擎原有的两轮上限；若新两轮仍失败，将等待下一次 cron 检查或手动检查。
- 最后更新时间依赖内容源声明；未提供 `updatedAt` 的内容源不会显示该字段。
