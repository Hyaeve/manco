# Manco v0.6.2 发布总结

## 阶段目标

- 修复上一版引入的本地仓库空白页。
- 恢复插件源枚举（不再误报「该扩展没有新增可添加的内容源」）。
- 非内置来源支持自定义名称。
- 来源胶囊限宽、滚轮不带动页面、页面浮出动画修复。

## 实际改动

### 修复

- **本地仓库空白**：上一版给本地仓库列表加二级排序时用了 `watch([sortMode, sortDesc], ...)`，但 `LocalLibraryView.vue` 的 vue 导入里没有 `watch`，组件在 setup 阶段抛 `watch is not defined`，整个视图渲染不出来。已补上导入。这类错误 `npm run build` 不会报，只有运行时才炸。
- **「该扩展没有新增可添加的内容源」**：探测式枚举用「安装前/后来源差集」判定，扩展之前装过时差集为空而被当成失败。现在差集为空时兜底调用 `pendingPluginSources`（`runtime.Sources()` 减去自定义源里已有的 `sourceName`），列出尚未添加的来源；确实一无所获才报「插件未声明任何可用内容源」。

### 新功能

- **非内置来源自定义名称**：新增 `PUT /api/custom-sources/{id}/name`（`handleRenameCustomSource`），只改 `CustomSource.Name` 后 upsert + `ReloadCustomSources` + `PersistSources`，不动来源 ID、config、icon 与运行时路由。编辑弹窗新增「内容源名称」输入框（仅非内置），保存时与账号设置一并提交。

### 界面

- 订阅卡片标题行去掉 `（内容源 ●）` 文本，右上角仍保留内容源图标作为启停入口。
- 探索发现来源胶囊 `max-width: 5em` + 省略号，超长名称不再撑宽。
- `handleStripWheel` 改为在该行上一律 `preventDefault`，滚轮到最左/最右也不再带动整页上下滚。
- 页面浮出动画：根因是 `KeepAlive` 缓存视图、`animation` 不会重播。现在由 `App.vue` 的路由 watcher 在每次切换时先摘掉、`nextTick` 后再加 `.page-enter`，400ms 后移除；CSS 改为 `.content-scroll.page-enter > *`，保留 `prefers-reduced-motion` 兜底。
