# Manco v0.9.5 发布总结

## 阶段目标

本次为常规版本，承接 v0.9.4。目标是调整信息总览横幅海报尺寸，统一探索发现与本地仓库的封面网格规格，并移除应用内原生链接悬停时触发的浏览器 URL 状态提示。

遵循先推送代码和标签、再补总结的顺序，不移动已有版本标签。

## 实际改动

### 横幅海报

- 横幅封面高度改为占满窗口内容区，宽度按 2:3 比例自动放大。
- 窗口上下内边距统一为 22px，不再在封面顶部堆积大块空白。
- 文字区与封面同高，骨架加载状态使用相同尺寸逻辑。
- 移动端同步按可用高度放大封面，只缩小左右间距。

### 统一封面网格

- 新增 `coverGrid` 工具，探索发现和本地仓库共用实际容器宽度列数算法。
- 两页统一每页最多七行、14px 间距、2:3 封面比例。
- 本地仓库会在首次加载、窗口缩放、浏览器缩放和页面重新激活时重新测量列数。
- 两页分页数量与实际列数同步，避免探索发现比本地仓库多出列数。

### 外链交互

- 新增统一的新窗口打开工具，使用 `noopener,noreferrer`。
- 登录页 Bangumi 外链、作品详情原站、视频播放、Bangumi Key 申请和 GitHub 入口全部由 `<a href>` 改为可访问按钮。
- 应用内不再保留原生 `href` 链接，悬浮内容时不会出现浏览器左下角或右下角 URL 状态文本。
