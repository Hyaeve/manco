# Manco v0.5.3 发布总结

## 阶段目标

- 书籍下载统一为 EPUB 格式，不再生成书籍 CBZ。
- 本地仓库能够直接阅读下载得到的 EPUB，而不是把二进制当文本显示。
- 修复内置禁漫天堂下载的 CBZ 图片解扰错乱问题。

## 实际改动

### 书籍下载统一 EPUB

- 新增 EPUB 3 写入器，结构包含 `mimetype`（ZIP 首项且不压缩）、`META-INF/container.xml`、`OEBPS/content.opf`、`nav.xhtml`、`toc.ncx`、样式表、章节 XHTML 与图片资源。
- 归档结束先写 `.part` 再重命名，失败不会留下半成品书籍。
- 插件书籍章节、纯文本正文和 `.txt` 文件都打包为 EPUB；写入前统一归一化章节正文，纯文本按段落转换。
- Z-Library 等来源返回的原生 `.epub` 原样保留；PDF、MOBI、AZW3 等无法转换的格式返回明确错误，不再静默落盘为其他格式。
- 漫画链路保持不变，仍是一话一个 CBZ。

### 本地仓库 EPUB 阅读

- 新增 `GET /api/local/epub`：解析 `container.xml` 与包文档，按 spine 顺序返回可阅读章节，并从章节标题或首个标题元素提取章节名。
- 新增 `GET /api/local/epub/file`：按条目流式输出 EPUB 内图片等资源。
- 章节 HTML 会剥离脚本、内联事件、`iframe` 与表单等元素，并把章节内图片重写到本地 EPUB 条目地址。
- 本地仓库阅读窗口识别 `.epub`，按章节渲染正文与插图。

### 禁漫天堂解扰修复

- `Pages` 改为每张图按自身文件名计算解扰段数，不再复用第一张图的结果。
- `scrambleParts` 以**不含扩展名的文件名**参与 MD5，`>421926` 使用基准 8、`268850..421926` 使用基准 10，对齐 Kototoro/Kotatsu 的 `JmComicParser.computeScrambleSegments`。
- `Descramble` 的分块映射改为参考实现：自底向上反向搬移，余数归最底部块，修正图片高度不能被段数整除时的整体错位。

### 版本

- 后端应用版本由 `v0.5.2` 提升到 `v0.5.3`，README 镜像标签示例同步更新。

## 已知问题

- 之前下载的禁漫天堂 CBZ 内部已经是错误图片，无法自动还原，需要删除后通过订阅「补全」重新下载。
- 已存在的书籍 CBZ 不会自动转换；重新下载后会得到 EPUB。
- 不支持 EPUB 的电子书来源（如返回 PDF/MOBI）会直接报错，当前不会做格式转换。
- 本机没有 Docker，容器镜像由 GitHub Actions 构建，NAS 侧需在流水线完成后拉取验收。
