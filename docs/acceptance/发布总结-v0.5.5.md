# Manco v0.5.5 发布总结

## 阶段目标

- 活动通知从「一章一条」收敛为「一个作品一条」，只呈现汇总结果。
- 订阅任务设置、本地仓库角标与多选交互按既定视觉规范统一。
- 内容源支持默认下载位置，并在订阅时自动套用。
- 新增 Telegram 机器人：指令交互 + 例行通知。
- 顺带修复前三项遗留问题：资源拓展插件源排序、插件详情运行时路由、禁漫单图分块解扰。

## 实际改动

### 活动通知

- 后端 `handleActivity` 改为按 `sourceId + comicId` 聚合，输出 `succeeded`、`failed`、`pending`、`total`。
- 前端通知列表改为显示作品名 + 成功/失败/待处理章节数。
- 不再因为单章下载失败就产生一条通知。

### 订阅任务设置与内容源默认位置

- 章节标符、封面模糊、繁转简从方框勾选改为和历史章节、自动追更一致的图标 + 文字圆角按钮，选中时高亮。
- `SourceDownloadSettings` 新增 `defaultDownloadDir`，内容源编辑窗口的「下载策略」增加目录选择器。
- 订阅时优先使用内容源默认位置，其次上次使用的目录，订阅窗口内仍可手动修改。
- 内容源编辑窗口排版压缩：section 间距、字段间距、说明行高收紧，多字段一行对齐。

### 本地仓库

- 封面右上角章数角标改为偏橘 `#E07A2F`。
- 多选勾选从右上角移到封面左上角，同样使用橘色加深色描边。

### Telegram 通知

- 新增 `internal/telegram`：长轮询、指令解析、结果渲染、例行通知。
- 系统设置新增 TG 面板：启用开关、Bot Token、允许的 Chat ID、TG 专用代理。
- 指令：`/start`、`/subscriptions`、`/sources`、`/s`；中文「搜索漫画 关键词」「<内容源>搜索 关键词」；「检查/补全/全量/归档/删除 + 作品名」。
- 全局搜索按资源拓展顺序取前三个内容源各三条；指定内容源搜索取前五条。
- 结果格式「作品名（内容源简称）」：中文内容源取前两字，英文内容源保留全名，标题过长截断且保证来源可见。
- 结果带内联按钮：进入详情显示封面信息、作者与最新章节，并提供「返回」「订阅」。
- TG 订阅套用内容源默认下载位置，默认开启繁转简、历史章节、自动追更，按当前整点生成每周 cron，创建后立即入队。
- 例行通知：cron 检查到新章节时推送汇总。

### 前序修复

- 资源拓展插件源拖拽排序：`handleSourceOrder` 改为严格弱序，内置源固定注册表顺序且始终最前。
- 插件源详情页报「无法确定内容源所属插件运行时」：`Adapter.call` 统一注入 `sourceName`。
- 禁漫单图拼接：`Descramble` 按参考解码器的矩形布局重写，余数归最前源块。
- 全量语义：清空成功/失败记录、删除已存在章节文件后重新拉取覆盖；网页与 TG 共用同一实现。

## 已知问题

- TG 机器人需要用户自行在 @BotFather 创建并填入 Token，并把聊天 ID 加进允许列表。
- TG 的搜索结果依赖各内容源自身的搜索接口和排序能力，不同来源的“权重”即为该来源返回的顺序。
- 全局搜索只取资源拓展顺序里的前三个内容源，避免一次请求过多来源。
