# Manco v0.5.8 发布总结

## 阶段目标

- 修掉「全局下载并发」名不副实的问题，并补上全局下载设置窗口。
- 任务列表分页化，不再一次性加载整张任务表。
- 详情页首屏复用列表数据、封面缩略图化，降低内存与滚动卡顿。
- 收尾插件内容源相关的资源占用（枚举、图片缓存、插件源持久化、拖拽排序）。

## 实际改动

### 下载并发

- `maxChapterConcurrency` 以前在 `SetConcurrency` 里被写成 `chapters × len(sourceConcurrency)`、在 `SetSourceConcurrency` / `SetSourceSettings` 里被写成各来源上限之和——**来源越多全局上限越大**，20 个来源各限 1 章就等于 20 章同时下。
- 现在 `maxChapterConcurrency` 是真正的全局上限；`claim()` 先卡全局再卡单来源；单来源上限改成「显式覆盖优先，否则用 `defaultSourceConcurrency`」，没单独配过的来源不再等于无限。
- 设置里的 `max_chapter_concurrency` / `max_page_concurrency` 以前只落库从不应用（改完必须重启且实际不生效），现在启动时与保存后都会 `SetConcurrency`，立即对新章节生效。
- 系统设置新增「下载设置」卡片：全局同时下载章节数（1–8）、每章图片并发（1–16）、每下载 N 章后暂停 M 分钟（0 = 不暂停）。

### 任务列表分页

- 之前 `GET /api/downloads` 不带 limit 时会把整张 `download_jobs` 表查出来，并且对**每一条**都做文件系统操作（查本地封面、缺元数据时读 `ComicInfo.xml`），几万条完成记录就是几万次 NAS 访问加一个巨型 JSON。
- 新增 `Store.DownloadJobPage(ctx, status, limit, offset)`（`status=active|completed`，同时返回总数）；`handleListDownloads` 支持 `status` / `limit` / `offset` 并返回 `total`，不带 `status` 时保持旧行为。
- 任务列表首屏只取 200 条（`active`），虚拟列表滚到已加载末尾时静默追页，任意视图下可用「加载更多（已加载 X / Y）」按钮；4 秒静默轮询按已加载条数取，翻过的页不会被缩回去。完成列表同样改成 `status=completed` 分页 300 条。
- 服务端 `localMetadataForJob` 结果按作品在请求内缓存（同一部作品的几十个章节只读一次 `ComicInfo.xml`）；`localCoverForDir` 增加 30 秒 TTL 缓存（只缓存命中结果，保证新下载的封面立刻可见）。

### 详情页与封面

- 新增模块级 `comicPreview` 存储：探索发现点卡片时先存下列表数据，详情页一进来就用它渲染标题/封面/作者/标签，`api.comic()` 返回后再覆盖并补章节，不再整页白屏。
- 新增缩略图服务 `internal/api/thumbnail.go`：`?w=` 时读原图 → 解码（jpeg/png/gif/webp）→ `draw.CatmullRom` 等比缩放 → JPEG(q82)，按「路径+大小+mtime+宽度」sha 键缓存到 `<dataDir>/thumbnails/`；解码失败、非图片、原图本来不宽都回退原图。接入 `/api/local/file?w=` 与 `/api/proxy/image?w=`，列表封面统一传 320，详情大图/阅读器/下载仍走原图。

### 插件内容源

- 打开「添加内容源」不再批量安装：按需枚举 + `extension_source_cache` 持久缓存（按仓库+扩展+版本）+ `InstallIsolated` 探测式差集（只返回该扩展新引入的来源）+ 枚举后 `PrunePlugins` 清理无主插件。
- 启动时先 `PruneUnusedPlugins`（清理历史遗留的几百个无用扩展——这是 sidecar 每次重启都全量加载、整站变慢的主因），再 `RestorePluginSources`（补装已添加来源引用但缺失的插件），保证插件源持久可用。
- 插件图片物化缓存 `<dataDir>/<host>/images` 增加 TTL 清理：启动清一次、之后每 6 小时一次，只删 24 小时前的文件。
- 拖拽排序改用独立 `PUT /api/sources/order`：以前借某个内容源的 PATCH 夹带 order，目标源查不到就整个请求 404，表现成「拖了没生效」。

### 其它同批修正

- TG：修复「填了 Token 启用后不轮询」（`Configure` 只在已运行时重启）；复用应用 HTTP 客户端从而跟随系统代理；新增「刮削 作品名」指令。
- 订阅：新增「刮削」批量操作（重拉元数据覆盖 `ComicInfo.xml` / `series.json` / 封面）；「自动追更」默认勾选且 Cron 留空＝不做定时检查；订阅页不再每 5 秒拉 500 条任务，快照写盘加内容校验。
- 界面：多选胶囊条统一样式；模糊封面改为悬浮解除并加橘色悬浮描边；订阅卡片显示最近执行时间；夜间模式改为暖色卡通配色；滚动条高亮减淡。
- 语义：作品详情页「只下载」不再隐式写入订阅清单。
