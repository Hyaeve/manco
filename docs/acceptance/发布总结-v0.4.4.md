# Manco v0.4.4 发布总结

## 阶段目标

- 统一下拉选择器和选择浮层的高亮视觉，改用项目侧栏系的浅黄色，移除原先偏蓝的交互色。
- 保持键盘焦点、当前选项和鼠标悬浮状态可辨识，同时不改变选择器行为。

## 实际改动

- 新增浅黄色选择高亮变量，分别适配明色与暗色主题。
- 站点/域名选择器、圆角下拉选择器、章节排序菜单统一使用浅黄色焦点和选项高亮。
- 原生 `select` 的聚焦状态与可支持浏览器中的选项状态同步改为浅黄色。
