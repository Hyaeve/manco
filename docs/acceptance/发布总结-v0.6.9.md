# Manco v0.6.9 发布总结

## 阶段目标

本版本合并 `v0.6.8` 之后的全部未发布改动，重点完成 Telegram 搜索与通知体验、插件管理、章节流式预览、信息总览视觉与交互、下载队列优先级，以及日间/夜间海报主题适配。

## Telegram 与通知

- Telegram 搜索、指定来源搜索和榜单结果改为“首条作品封面 + 候选按钮”的消息形式。
- `搜索 作品名` 覆盖漫画源、书籍源和其他源，并按来源类型分页展示权重最高的结果。
- 支持漫画、书籍、其他源类型限定搜索，以及具体内容源限定搜索。
- 从作品详情返回搜索结果时，恢复原来的结果页和翻页状态。
- 无可用封面或 Telegram 图片发送失败时，自动回退为文本消息。

## 插件与图片运行时

- 插件文件改为使用插件显示名称命名，中文自动转换为无声调拼音，英文和数字直接保留。
- 插件更新时先加载新文件，成功后再清理旧文件；失败时保留原插件。
- 增加插件来源图片域名动态登记，封面和章节图片按所属内容源授权，避免合法 CDN 被静态白名单误拦截。
- 图片代理仍要求来源与登记域名匹配，并继续执行公网主机校验。

## 章节预览

- 章节预览从一次性加载整章图片改为流式分块加载。
- 打开预览时先加载前 6 张，接近底部后继续追加，避免一次性创建大量图片节点。
- 关闭预览时清理页面 URL 和图片 DOM。
- 插件章节图片继续由插件运行时完成签名、请求头和解扰，下载器不做二次解扰。

## 订阅计划与批量操作

- 订阅计划多选操作条将“全量、补全、归档”收纳到三点菜单，新增“模糊”批量操作。
- 模糊操作会把所选订阅卡片的 `coverBlur` 持久化为开启。
- 切换作品父目录或来源分类时，旧内容先淡出，新内容返回后在原位短距离浮现。
- 使用独立切换序号，避免后台轮询或其他并发请求导致目录切换状态卡住。
- 支持减少动态效果的系统设置，开启后自动关闭相关过渡动画。

## 信息总览

- 轮播间隔调整为 10 秒，背景和内容按切换方向横向滑动。
- 日间主题改为侧栏同系浅色背景，保留封面放大、模糊和磨砂叠层。
- 夜间主题保留深色遮罩、白色文字和白色轮播圆点。
- 修复 Vue 深色主题全局选择器误命中根节点，导致夜间整页被模糊的问题。
- 统计总览、资源拓展、下载队列和订阅计划压缩布局，常见桌面尺寸无需页面滚动即可看到全部窗口。
- 窗口标题和线条图标放大；统计条目图标放大并增加左侧留白。
- 下载队列在进度条右上方显示实时百分比，排队任务显示 0%。
- 订阅计划窗口按可用高度均分三行，封面保持竖版比例。
- 资源拓展使用固定两行布局，内容源图标放大、圆角化并移除外层卡片框。
- 模糊封面增加磨砂叠层；鼠标悬浮时临时解除模糊，移出后恢复。
- 未启用订阅卡片改为浅灰偏白，不再使用近似黑白遗照的灰色。

## 下载队列

- 下载任务新增持久化 `queue_priority`。
- 手动检查、全量、补全、重试、直接下载，以及网页或 Telegram 触发的订阅历史章节任务，排在例行 Cron 任务之前。
- 同优先级继续按入队顺序执行。
- 容器重启恢复运行中或取消任务时保留原队列优先级，手动任务恢复后仍然优先。

## 已知限制

- Mihon 系 Android/JVM APK 插件仍只登记清单，尚未提供桌面兼容运行时。
