# Manco v0.5.7 发布总结

## 阶段目标

- 多选操作胶囊条统一成订阅清单那套扁平样式，并新增「刮削」操作（网页 + TG 指令）。
- 作品详情页「只下载」不再隐式写入订阅清单。
- 收敛前几轮遗留：扩展枚举不再整批安装、TG 启用即生效并跟随系统代理、追更 Cron 留空即停用、模糊封面改为悬浮解除、整站加载提速。

## 实际改动

### 多选操作胶囊条统一

- `.selection-pill`（任务列表）、`.source-selection-bar`（资源拓展）、`.local-selection-bar`（本地仓库）统一到订阅清单那套：14px 圆角容器、同一磨砂底与阴影、按钮**不带边框与背景**，悬浮时才出现 `border-radius: 999px` 的主色 16% 高亮块；危险按钮改用 `--danger` 文字与 16% 危险色高亮。
- 此前任务列表 / 资源拓展 / 本地仓库沿用的是带边框的 `secondary` / `primary` / `danger` 按钮，与订阅清单不一致。

### 刮削（scrape）

- `Engine.EnsureSeriesMetadata` 抽出 `writeSeriesMetadata(ctx, sub, force)`；新增 `ScrapeSeriesMetadata`，强制重新拉取上游详情并覆盖本地 `ComicInfo.xml` / `series.json` / `cover.*`。普通检查仍走 `force=false`，只在文件缺失或过期时补写。
- 新增 `POST /api/subscriptions/{id}/scrape` 与 `api.scrapeSubscription`。
- 订阅清单胶囊条在「补全」后新增「刮削」按钮（二次确认、批量执行）。
- TG：`actionAliases` 增加 `刮削 → scrape`，帮助文本加「刮削 作品名」，`runAction` 新增 `scrape` 分支，`App` 接口加 `BotScrape`，`internal/api/telegram_bot.go` 实现为调用 `ScrapeSeriesMetadata`。

### 下载不再隐式订阅

- 作品详情页的下载弹窗会把订阅弹窗共享的 `autoDownload`（默认 true）一起发给下载接口，而 `handleCreateDownload` 结尾有一段 `if payload.AutoDownload { UpsertSubscription(...) }`，导致「只点下载」也会在订阅清单里生成一条带默认每周 cron 的订阅。
- 现在后端删掉这段隐式订阅，前端下载载荷显式传 `autoDownload: false`。`UpsertSubscription` 只剩「订阅任务设置」和 TG 订阅指令两处调用。

### 扩展枚举与整站加载速度

- **打开添加内容源窗口不再批量安装**：改为按需——选中仓库后点某个拓展的「加载内容源」只装这一个；结果按「仓库 + 扩展 + 版本」持久化到新表 `extension_source_cache`，重复点击 / 换浏览器 / 重启容器都直接命中缓存，`?refresh=1` 可强制重算。
- **探测式枚举**：`InstallIsolated` 只返回该扩展新引入的来源（sidecar 的 metadata 会报告整个运行时所有插件，需做差集），避免把别的插件来源算到它头上。
- **枚举后清理**：`PrunePlugins` 删掉没有被任何已添加来源引用的插件；`PruneUnusedPlugins` 在启动时也跑一次，自动清掉历史遗留的几百个无用扩展（这是此前 sidecar 每次重启都要全量加载、整站变慢的主因）。
- **按需补装**：候选配置带上 `installUrl`，添加来源时若插件已被清理会自动补装。
- **不再重复下发仓库清单**：`repositoryView` 解析出 `extensions` 后清空 `catalog`，避免把几 MB 的清单原文随 `/api/repositories` 再发一遍。
- **本地封面缓存**：`localCoverForDir` 增加 30 秒 TTL 缓存（只缓存命中结果），订阅页每 5 秒轮询时不再对每个订阅做一次 `filepath.Glob`。

### TG 通知

- 修复「填了 Token 启用后没反应」：`Service.Configure` 原来只在「已在运行且 Token 变化」时重启轮询，而启动未配置的实例 `started` 一直是 false，导致启用后永远不开始长轮询。现在只要「该跑但没跑」就真正 `Start`。
- TG 复用应用统一创建的 HTTP 客户端（共享 `source.ProxyController`），直接跟随系统设置里的代理，不再需要专用代理字段；换代理后 `CloseIdleConnections()` 让长轮询尽快用上新连接。长轮询超时 50 → 40 秒，给客户端 60 秒超时留余量。

### 订阅语义与界面细节

- 「自动追更」每次打开默认勾选；取消勾选会清空并禁用 Cron，重新勾选回填默认周期。后端 `cronutil.Due` 对空表达式一律判为未到期（原来会退化成 30 分钟固定间隔），创建订阅只有字段缺省才补默认值，更新时空串不再回退旧值。
- 订阅卡片下载目录下面新增一行「最近执行」时间（取自 `lastCheckedAt`，按本地时区显示，未执行过显示「尚未执行」）。
- 模糊封面改为**悬浮到封面才临时解除**，移开立即恢复，解除状态下点击直接进入作品详情页；悬浮卡片整体加橘色描边（`#e07a2f`）。
- 本地仓库网格悬浮时圆角框固定大小，只有封面放大提亮（新增裁切层 `.local-library-cover-frame`）。
- 功能开关按钮（TG 启用、订阅 / 下载任务设置）改为订阅卡片编辑窗口同款圆角框；系统设置保存按钮统一回主按钮配色；账号 / 代理 / TG 输入框支持回车保存。
- 侧栏副标题对齐 Manco 字标；通知窗口颜色更淡；夜间模式改为卡通暖色（可可底 + 奶油字 + 橘黄主色）；全站滚动条悬浮高亮减淡并把主内容区滑块从主色 40% 压回浅灰。

## 已知问题

- 刮削只覆盖本地已下载目录里的 `ComicInfo.xml` / `series.json` / `cover.*`；如果作品目录还不存在（没下过任何章节），接口返回「还没有可刮削的本地文件」。
- 本地封面缓存 TTL 30 秒且只缓存命中结果；负面结果不缓存，所以刚下载完的封面会立刻出现。
- 之前被隐式订阅写入清单的作品需要手动删除。
- 代理栏目只接受 `http://` / `https://`（这是应用统一 HTTP 客户端本身的限制），TG 跟随同一限制。
