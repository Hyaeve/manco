# Manco v0.9.7 发布总结

## 阶段目标

本次为常规版本，承接 v0.9.6。目标是让横幅海报 Tag 只显示能够完整放下的项目，减少探索发现和本地仓库每行封面数量，并统一 Bangumi 品牌 PNG 图标。

遵循先推送代码和标签、再补总结的顺序，不移动已有版本标签。

## 实际改动

### 横幅 Tag 完整显示

- 增加隐藏测量行，按横幅实际可用宽度逐个测量 Tag 宽度。
- 只渲染能够完整放入当前行的 Tag。
- 后续放不下的 Tag 直接隐藏，不再对当前 Tag 使用省略号或截断文字。
- 单行高度、Tag 间距、文字级模糊和悬浮恢复逻辑保持不变。

### 封面网格密度

- 探索发现和本地仓库继续共用同一列数工具，但每行在当前基础减少两列。
- 列数仍随实际网格宽度、浏览器缩放和页面重新激活更新。
- 分页数量继续与实际列数同步，每页保持七行。

### Bangumi 图标

- 新增 `source-icons/bangumi.png`，用于探索发现 Bangumi 分类入口。
- 待匹配 Bangumi 订阅卡片改用同一 PNG 图标。
- 分类入口按 18×18 显示，PNG 原始尺寸为 200×200。

## 已知限制

- Tag 是否显示取决于实际渲染宽度，因此不同字体缩放和语言环境下显示的 Tag 数量可能不同。
- 单行内第一个 Tag 本身宽于可用区域时，该行不会显示 Tag，避免截断。
