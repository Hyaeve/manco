# Manco v0.9.6 发布总结

## 阶段目标

本次为常规版本，承接 v0.9.5。目标是修正信息总览横幅海报的模糊表现：封面勾选模糊后，内容简介和 Tag 标签只模糊文字字形，不再对整个内容区域形成矩形滤镜。

遵循先推送代码和标签、再补总结的顺序，不移动已有版本标签。

## 实际改动

- 移除横幅简介与标签容器的整块 `filter: blur()`。
- 简介文字改为透明字色叠加双层 `text-shadow`，保留文字布局和换行轮廓。
- Tag 文本增加独立内层元素，只对文字字形应用模糊阴影。
- Tag 胶囊背景、边框、图标以及简介区域本身保持清晰，不产生模糊矩阵。
- 悬浮或键盘聚焦横幅内容时，简介与 Tag 文字恢复清晰显示。
- 封面海报自身的模糊效果和悬浮解锁逻辑保持不变。
