# Manco v0.10.1 发布总结

## 阶段目标

用户反馈在填写浏览器 Cookie 与 User-Agent 后，Z-Library 仍返回人机验证提示。本次修复程序中已复现的浏览器请求头解析和验证域名绑定问题，并增加不包含敏感值的诊断，帮助区分输入问题与站点会话失效。

本次为常规版本，承接 v0.10.0，发布为 v0.10.1。先推送代码和版本标签，再立即补写本总结，不移动历史标签。不将本次程序修正表述为已经恢复用户 NAS 上的真实站点访问。

## 实际改动

- Cookie 改用标准 `http.ParseCookie` 严格解析，支持可选的 `Cookie:` 前缀与分行输入，不再静默丢弃首项或格式错误的字段。
- 保留 Cookie 值中的百分号编码与等号；错误提示不回显凭据，拒绝空前缀输入、过长输入和混入其他请求头的错误格式。
- User-Agent 支持可选的 `User-Agent:` 前缀，拒绝换行注入和过长值，不在错误中回显原始输入。
- 明确选择网站地址后，只请求该域名，不再把该浏览器 Cookie 自动用于其他回退镜像。
- 手动配置浏览器 Cookie 时，要求同时指定验证网站；来源编辑窗口同步明确网站地址的域名绑定含义。
- 浏览器验证失败时，仅显示最终实际请求的 HTTP 状态、Cookie 数量、防护字段和登录字段有无、自定义 UA 有无及源代理开关，不输出 Cookie 值、UA 值、账号内容或响应正文。
- 诊断中的字段存在不代表验证有效，源代理开关也不等同于已证明实际网络出口一致。
- README 补充输入格式、域名绑定与诊断说明，应用版本和标签示例同步为 v0.10.1。
- 沿用已有接口，只增强错误文本，没有新增 API 或变更响应结构；既有共享客户端隔离、代理配置、重定向上限及跨站凭据保护保持不变。
