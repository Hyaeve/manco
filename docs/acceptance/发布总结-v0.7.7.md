# Manco v0.7.7 发布总结

## 阶段目标

本次为常规版本，承接 v0.7.6。作品详情页增加内容源作品原链接，仪表盘横幅只展示拥有封面的本地仓库作品。

遵循先推送代码和标签、再补总结的顺序，不移动已有版本标签。

## 实际改动

### 作品原链接

- 作品详情数据新增 `sourceUrl` 字段，由后端根据内容源和作品 ID 生成。
- 包子漫画、禁漫天堂、笔趣阁生成具体作品详情地址；哔咔漫画使用网页作品地址。
- 其他插件源无法可靠推导作品详情地址时，回退到内容源主页，不伪造详情路径。
- 详情页在封面底部左侧显示完整 URL，超过封面宽度时单行省略。
- 链接悬浮或键盘聚焦时使用侧栏同款淡黄高亮，点击通过新浏览器页面打开。
- 使用 `noopener noreferrer` 隔离新页面。

### 横幅海报封面过滤

- 本地仓库分页接口新增 `hasCover` 条件。
- 仪表盘横幅请求只返回本地封面、持久化缓存封面或来源封面至少存在一项的作品。
- 过滤在服务端分页前执行，因此不会先取 7 条再丢失无封面项，也不会在横幅中留下空位。
- 普通本地仓库页面不受该条件影响，无封面作品仍正常展示。
