# Manco v0.6.1 发布总结

## 阶段目标

- 订阅清单与本地仓库支持二级排序（字段 + 升降序），默认按执行时间降序并持久化。
- TG 订阅回执与例行检查通知按新样式重做（封面 + 作品信息 + 章节标题）。
- 活动通知条目显示作品封面并改为增量渲染。
- 下拉选择器配色统一、页面浮入与侧栏果冻动画。

## 实际改动

### 排序

- 新增共用组件 `cmd/manco/web/src/components/SortMenu.vue`：两段式弹层（上选字段、下选升降序，带勾选），沿用 `.chapter-sort-*` 类名，与本地仓库详情页外观一致；`onOutside` 关闭、下方空间不足时向上弹。
- **订阅清单**：筛选栏同行最右端接入，字段「执行时间 / 添加时间 / 标题」，默认**执行时间降序**，持久化到 `manco.subscriptions.sort.v1`；新增 `sortedItems`，`filteredItems` 从它开始过滤（排序与来源/目录筛选叠加）。
- **本地仓库列表**：目录胶囊行外包 `.local-root-row`，排序器贴最右；字段同上（执行时间取目录 `updatedAt`），持久化到 `manco.library.sort.v1`。
- **本地仓库详情页**：内联排序控件整块替换为 `SortMenu`，并清理随之失效的 ref/函数（`chapterSortOpen`、`chapterSortUpward`、`chapterSortRoot`、`toggleChapterSortMenu`、`chooseChapterSortMode`、`chooseChapterSortDirection`、`closeChapterSortOnOutside`）及其五处引用。

### TG

- `App.BotSubscribe` 增加第三个返回值（本次入队章节数）；订阅回执改为：
  `封面 → 作品名 → 作者（内容源简称）→ Cron → 完整下载位置 → 共 N 个章节待下载`，封面取不到时退回纯文本。
- `Notifier.SubscriptionChecked` 增加 `titles []string`；`scheduler.check` 入队时收集章节标题。例行检查通知改为封面 + 作品名 + 作者 + 本次更新的章节标题（最多 10 条，超出折叠为「其余 N 章」），新增 `notifyPhotoAll` 统一处理带图通知。

### 活动通知

- `/api/activity` 每条聚合结果新增 `cover`（取自发现缓存 `CachedCoverURL`，纯内存查表）。
- `App.vue` 通知条目：有封面则渲染 32×44 圆角缩略图，否则退回状态图标。
- 列表改为增量渲染：`ACTIVITY_PAGE_SIZE = 12`、`visibleActivity`、滚到底追加 12 条，每次打开重置。

### 样式

- 下拉选择器（`RoundedSelect` 触发器悬浮、弹层悬浮/选中项）统一改用侧栏选中态淡黄高亮（亮 `color-mix(#f9ee9f 82%, #eef4dd)` / 暗 `#3a2f1c`）。
- 页面模块浮入：`.content-scroll > *` 加 `manco-float-in`（上浮 10px + 淡入 0.32s），并遵守 `prefers-reduced-motion`。
- 侧栏图标果冻动画：`cubic-bezier(.34,1.56,.64,1)` 下 `scale(1.28)` + 右移 + `margin-right`，悬浮时把文字挤开。

## 已知问题

- TG `sendPhoto` 由 Telegram 自行抓取封面 URL，源站防盗链时会退回纯文字。
- 活动通知封面只能取到发现缓存里已有的封面；未缓存过封面的作品仍显示状态图标。
- 重复执行全量/补全不会产生重复任务（按 source+comic+chapter upsert）；插件源两次返回不同章节 ID 时仍会视为两章。
