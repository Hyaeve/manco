# Manco v0.9.4 发布总结

## 阶段目标

本次为常规版本，承接 v0.9.3。目标是完善 Bangumi 的请求缓存、个人 Key 与 429 限流提示，补齐登录页的订阅封面回退和最终留白状态，把 Bangumi 条目接入项目内作品详情页，并微调探索发现封面网格和 README 品牌展示。

遵循先推送代码和标签、再补总结的顺序，不移动已有版本标签。

## 实际改动

### Bangumi Key 与请求缓存

- 系统设置「账号与安全」新增「Bangumi Key」，随该区域保存。
- Key 输入框右侧增加「申请个人 Key」胶囊按钮，跳转 Bangumi Access Token 申请页。
- 填写 Key 后，Bangumi 栏目、搜索、详情、日历和登录页元数据请求统一携带 Bearer Token；留空继续使用公共请求。
- Bangumi 触发 429 时返回明确提示，引导填写个人 Key。
- 栏目、搜索和作品详情响应增加 30 分钟磁盘缓存。
- Bangumi 浏览与搜索封面复用 `discovercache` 持久化，后台抓取限制为 3 路并发，页面优先使用本地缓存封面。

### 登录页回退

- Bangumi 有数据时优先显示 Bangumi 海报和作品信息。
- Bangumi 无数据时，读取订阅计划中未勾选封面模糊且已有本地封面的作品，最多展示 10 部。
- Bangumi 与订阅回退均为空时，左侧保持与整体页面协调的浅橘色留白，不再显示占位图、小猫或画作。
- Bangumi 请求期间不提前渲染回退内容，避免先闪出占位状态。

### Bangumi 项目内详情

- 点击 Bangumi 探索发现条目进入项目现有作品详情页，不再直接打开外部站点。
- 详情页按 subject ID 获取 Bangumi 元数据，显示封面、标题、作者、标签、简介和原站链接。
- Bangumi 详情隐藏无意义章节区与下载按钮，保留订阅操作。
- 创建 Bangumi 订阅时保存原始作品 URL，供后续内容源匹配和卡片使用。
- 登录页原站链接仅高亮链接文字，不再增加背景圆角框。

### 探索发现与 README

- 探索发现封面网格按实际容器宽度计算原有 `132px` 卡片规格下的列数，再固定增加一列。
- 窗口缩放、浏览器缩放和侧栏断点变化时会重新测量，分页数量同步为每行新列数 × 7；其他页面间距和卡片布局不变。
- README 开头加入完整猫箱图标与 `Manco` 字标组合。

## 已知限制

- 登录页订阅回退只使用本地已经存在且未勾选封面模糊的封面，缺失封面会在后续请求中尝试物化。
- Bangumi 公共接口仍有全局限流；未填写个人 Key 时可能收到限流提示。
- 当前 Windows 验证环境缺少 `gcc`，无法执行 Go race detector。
