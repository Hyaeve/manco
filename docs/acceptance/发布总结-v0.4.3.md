# Manco v0.4.3 发布总结

## 发布信息

- 发布时间：2026-10-15
- 发布版本：`v0.4.3`
- 部署镜像：`ghcr.io/hyaeve/manco:v0.4.3`、`ghcr.io/hyaeve/manco:latest`
- 发布范围：插件内容源分类设置、站内导航交互和作品详情信息展示。

## 本版增改

### 1. 恢复插件内容源分类编辑

- 内容源分类支持按需加载运行时筛选，不再依赖首次注册时是否已经填充静态筛选。
- 保存分类显示设置时，后端使用同一份运行时筛选做校验并持久化停用状态。
- 插件来源的分类按钮增加加载状态，加载失败时显示明确提示。
- 已停用分类会在再次打开分类窗口时正确回显。

### 2. 移除站内跳转的浏览器地址提示

- 新增无原生 `href` 的站内跳转组件 `ContentLink.vue`。
- 总览、探索发现、搜索、订阅清单、归档集、任务列表和已完成页面改为使用站内跳转。
- 鼠标悬浮作品、订阅卡片和导航按钮时，不再在浏览器底部显示目标地址，同时保留鼠标和键盘操作。

### 3. 作品详情信息完整展示

- 作品详情右侧信息区不再受封面高度和简介行数限制。
- 作品名称可以自然换行，作者、简介和标签内容可以完整向下展开。
- 信息区增高时正常推动下方章节区域，不遮挡章节内容。

### 4. 版本同步

- 后端应用版本更新为 `v0.4.3`。
- README 发布示例更新为 `v0.4.3`。
