# Manco v0.4.5 发布总结

## 阶段目标

- 插件来源的书籍章节统一下载为 `.cbz`，与 Kototoro 的章节归档结构保持一致。
- 内置书籍源继续优先保存 EPUB、PDF 等原始文件，不改变 Z-Library 等现有行为。

## 实际改动

- 新增统一书籍章节归档接口，插件适配器返回正文 HTML 与插件图片页，不绕过 JVM sidecar。
- 插件书籍章节生成的 CBZ 包含章节 HTML、插图、`index.json` 和 `ComicInfo.xml`。
- HTML 中的插图地址会改写为归档内文件名，`index.json` 同步记录远程地址与本地文件映射。
- 下载优先级固定为：原始电子书文件 > 插件章节归档 > 纯文本正文。
- 书籍归档的 `ComicInfo.xml` 写入书籍类型标签，并使用 `Manga=No`。
