# Manco v0.4.8 发布总结

## 阶段目标

- 将订阅下载与探索发现缓存生成的 `ComicInfo.xml` 严格对齐 Anansi ComicInfo v2.1 规范，确保 Komga、KMRS 等阅读器可以稳定读取。
- 删除旧实现中不符合规范的 `Status` 元素，修正成人分级枚举和 XML 元素顺序。
- 在本地协作规则中明确：所有推送说明必须使用中文。

## 实际改动

### ComicInfo v2.1 兼容

- `internal/downloader/downloader.go` 按 ComicInfo v2.1 XSD 的 `xs:sequence` 顺序重排完整字段集，包括 `AlternateCount`、`Imprint`、`Format`、`BlackAndWhite`、`Characters`、`Teams`、`Locations`、`ScanInformation`、`StoryArc`、`StoryArcNumber`、`Pages`、`CommunityRating`、`MainCharacterOrTeam`、`Review`、`GTIN` 等。
- 章节 CBZ 内嵌的 `ComicInfo.xml` 写入规范 `Pages/Page` 数据，每个 `Page` 使用 0 起始的 `Image` 索引和 `Type="Story"`。
- 移除非规范 `Status` 元素；作品状态继续由 Mylar 可读取的 `series.json` 保存。
- ComicInfo 成人分级改为合法枚举 `Adults Only 18+`；`series.json` 继续使用 Mylar 的 `Adult`，两种格式不再混用。
- 作品目录根部的 `ComicInfo.xml` 保持作品级语义，不写入章节的 `PageCount` 或 `Pages`。
- `internal/api/server.go` 的本地仓库元数据读取继续兼容旧文件里的 `<Status>`，已有中文状态不会因升级而丢失。
- `internal/discovercache/cache.go` 同步移除非法 `<Source>` 元素，来源信息改写入 `Notes`，并补充 `LanguageISO`、`Tags` 和 `Manga`。

### 协作规则

- `AGENTS.md` 增加硬性规则：提交信息、发布总结、标签说明、推送验收说明和给用户的推送结果说明必须使用中文。

## 已知问题

- 历史下载的旧 CBZ 不会在本版本中自动执行原地 ZIP 重写，旧作品需要重新下载章节才能获得新的内嵌 ComicInfo v2.1。
- 重新下载可通过移出旧作品目录后点击订阅卡片“补全”完成，系统会把文件不存在的已完成记录重新入队。
- 本机未安装 Docker CLI，镜像构建结果以 GitHub Actions 和 GHCR 为准。
