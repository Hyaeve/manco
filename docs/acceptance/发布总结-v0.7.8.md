# Manco v0.7.8 发布总结

## 阶段目标

本次为常规版本，承接 v0.7.7。修复本地仓库和订阅计划在数据窗口尚未返回时仍可继续向下滑入空白区域的问题。

遵循先推送代码和标签、再补总结的顺序，不移动已有版本标签。

## 实际改动

### 加载期间滚动锁

- 本地仓库记录页面最后有效滚动位置。
- 首屏载入、筛选重载或虚拟网格窗口请求期间，如果用户继续向下滚动，会恢复到加载前位置。
- 加载期间仍允许向上滚动，用户可以回看已加载内容。
- 数据窗口返回后自动解除锁定，用户可继续下滑。

### 订阅计划

- 订阅计划在首屏加载、排序或筛选重载、分页追加期间应用同样的向下滚动锁。
- 滚动处理仍使用 requestAnimationFrame 合并事件，避免滚动时重复计算虚拟窗口。
- 切换类型或父目录时重置滚动基准。
- 加载完成后，新分页或新窗口进入列表，继续下滑不再被拦截。
