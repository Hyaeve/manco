# Manco v0.7.5 发布总结

## 阶段目标

本次为常规版本，承接 v0.7.4。重点是降低本地仓库和任务列表首屏数据量，改为只保留当前滚动窗口；同时完善活动通知作品封面、漫画源语义图标和任务列表多选操作栏。

遵循先推送代码和标签、再补总结的顺序，不移动已有版本标签。

## 实际改动

### 本地仓库窗口化

- 首屏不再固定加载 60 部作品，而是按当前视口高度和网格列数估算可见行加一行。
- `WindowedGrid` 新增总数、数据偏移和窗口范围事件；网格测量后按真实列宽、行高及视口校正请求范围。
- 滚动时只保留可视区域及上下缓冲，离开窗口的作品数组会被替换释放，滚动条仍按完整总数展示。
- 本地搜索、漫画/书籍/视频类型、下载目录和标题/添加时间排序改为服务端分页执行，避免释放数据后搜索不到旧作品。
- 服务端返回根目录范围内的分类计数；类型切换不会因当前窗口内容变化而出现错误数量。
- 多选项使用轻量快照保留，窗口替换后仍可继续繁转简、合并或删除。

### 任务列表窗口化

- 移除固定 100 条首屏和滚动追加累积。
- 根据任务行高与内容视口只请求当前可视行加两行缓冲。
- 向下滚动超过窗口释放阈值时请求新窗口并替换旧数据；向上滚动时重新请求上方窗口。
- 列表总任务数继续用于计算完整滚动高度，避免窗口化后滚动条缩短。
- 当前窗口定时轮询刷新状态；离开窗口的已选任务保留快照，供批量重试或删除使用。
- 删除已不再使用的任务列表页码合并工具及其测试。

### 任务操作栏

- 任务列表底部胶囊操作条单独增加按钮间距。
- 按钮悬浮和键盘聚焦时显示柔和的胶囊高亮、内描边和轻微上浮反馈。
- 删除按钮继续使用语义化危险色高亮；订阅、归档和探索发现操作栏不受该调整影响。

### 活动通知作品封面

- 活动聚合查询补充下载任务保存的作品来源封面。
- 后端优先返回持久化订阅封面索引或发现缓存，前端缺失时通过图片代理加载作品来源封面。
- 完全无封面时显示书籍占位，不再使用下载状态图标代替作品封面。

### 漫画源图标

- 新增双页分格加对话气泡的漫画源线稿图标。
- 探索发现、订阅计划和资源拓展的漫画源栏目统一使用该图标。
- 书籍源、视频源和拓展仓库分别使用翻书、场记板和资源箱图标。
- 来源图片不可用时，漫画、书籍和视频的默认回退图标同步使用对应语义。

## 已知限制

- 窗口化通过服务端分页和滚动位置驱动；快速拖动超长滚动条时，新窗口返回前会短暂显示空白占位。
- 本地仓库首次扫描仍由服务端遍历下载目录并缓存结果，本次主要减少浏览器端传输、列表数组和 DOM 数据量。
- 跨窗口 Shift 连续选择只能选中当前已加载窗口内的项目；普通逐项选择与已选快照不受窗口替换影响。
- 本版本未修改 JVM 插件运行时，镜像体积与 v0.7.4 相同。
