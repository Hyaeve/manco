# Manco v0.5.2 发布总结

## 阶段目标

- 让活动通知实时反映终态任务，并补齐完成结果、仓库名称和来源编辑信息。
- 统一本地仓库、订阅与归档页面的筛选、封面悬浮和多选交互。
- 完成列表独立展示作品详情，探索发现显示具体最新章节名称。
- 新增合并下载能力：默认仍为一章一个 CBZ，也可将所选章节合并为一个 CBZ。

## 实际改动

### 活动通知与扩展仓库

- 活动通知每 15 秒静默轮询，有新消息时实时更新数量，不再依赖点击后才刷新。
- 排队中和运行中的任务不进入通知窗口，只显示完成、失败、取消等终态结果。
- 拓展仓库名称留空时自动采用清单名称；填写自定义名称时保存并显示自定义名称。
- 插件来源编辑窗口顶部显示所属拓展仓库名称，并隐藏窗口内部的滚动条视觉样式。

### 本地仓库与作品详情

- 本地仓库新增“其他源”栏目，并按来源类型过滤作品。
- 网格封面下作品名称适度加粗；从网格进入作品详情时始终滚动到页面顶部。
- 探索发现作品详情的时间排序图标放大，最新、最旧按钮更易辨认。
- 探索发现作品卡片的更新信息改为具体章节名：连载显示“更新至 {最新章节名}”，完结显示“完结至 {最后章节名}”。

### 订阅、归档与任务列表

- 订阅卡片和归档卡片支持右键进入多选、左键切换、Shift 连选；Shift 操作不再触发文本选择。
- 卡片封面悬浮时复用本地仓库的提亮和轻微放大动画。
- 底部胶囊操作条加入磨砂背景，切换侧栏页面时自动退出多选状态。
- 任务列表的已完成栏目改名为“完成列表”，进入独立页面并使用区别于其他栏目的高亮色。
- 完成列表页左上角标题独立，返回按钮改为更大的图标加文字样式。
- 完成列表折叠条目展示封面、作品名、作者、作者胶囊、简介和标签，内容超出时截断且不增加条目高度。
- 完成列表改为增量渲染，不再一次性加载全部完成记录。

### 订阅与下载设置

- 订阅设置中的“订阅全部章节”改为“历史章节”，“开启自动追更”改为“自动追更”。
- 两个设置统一为同一行带图标和文字的功能按钮，开启时使用高亮色块。
- 下载任务设置同步使用相同功能按钮，并新增“合并下载”开关。
- “合并下载”默认关闭，保持一话一个 CBZ；开启后把当前所选章节合并成一个 CBZ。
- 合并漫画时按章节顺序和章节内图片顺序编号，例如 `001-0001.png`、`001-0002.png`、`002-0001.png`。
- 合并插件书籍时，将 HTML、图片、索引和 ComicInfo 一并放入同一个 CBZ；不支持合并的书籍源返回明确错误。

## 已知问题

- 合并下载只适用于源能返回可归档章节的文件；普通书籍源若没有 Kototoro 风格章节归档能力，会明确提示不支持。
- 合并下载会创建一个包含多个逻辑章节的 CBZ；默认的一话一个 CBZ 行为不受影响。
- 本机没有 Docker，容器镜像由 GitHub Actions 构建，NAS 侧需要拉取 `v0.5.2` 后验收。
