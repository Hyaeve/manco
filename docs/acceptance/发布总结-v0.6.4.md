# Manco v0.6.4 发布总结

## 阶段目标

订阅卡片编辑窗口、订阅任务设置、下载任务设置的功能项统一为一个组件；侧栏选中态与全站选中高亮统一为淡橘；运行日志条目上限可配（默认 10000）并落盘保留 30 天；支持上传 APK 格式插件源。

## 实际改动

### 功能项组件化

新增 components/FunctionOption.vue（圆角框 + 勾选方框 + 文字，role=checkbox）与 .function-option-grid（四列网格、10px 间隔、窄屏两列）。三处统一使用：订阅卡片编辑窗口、订阅任务设置（5 项，第二行 1 项）、下载任务设置（3 项）。

### 选中态与配色

侧栏选中态改为 14px 圆角、淡橘底 #fdf0e5 + 深色字 + 橘色图标（暗色 #3a2f1c / #ffd88a），按钮字号 14.5px、图标 20px。全站 --primary-soft / --select-highlight / --select-highlight-strong / --select-highlight-text 亮暗两套都改为淡橘。排序选择器按钮从顶部工具栏移到目录胶囊行最右，选中/悬浮改淡橘。设置页保存按钮最小宽度 88px。

### 运行日志

logbuf 默认容量 10000，新增 SetMax（缩容丢最旧）与 SetFileSink（按天写 <dataDir>/logs/manco-YYYY-MM-DD.log，并按保留天数清理）。新增设置项 log_max_entries（100-200000）与 log_retention_days（0-3650），启动时应用、保存时立即生效；/api/logs 的 limit 上限放宽到 200000。系统设置新增「运行日志」卡片。

### APK 源导入

新增 Manager.InstallFile：安装本地上传的 .apk/.jar（复制到 plugins、注册、重启 sidecar、metadata 枚举、失败回滚）。新增 POST /api/plugins/install-apk（multipart，256MB），返回内容源候选。添加内容源窗口工具栏新增「添加 APK 源」按钮 + 隐藏文件选择框，上传成功后候选并入列表。

## 已知问题

APK 源没有 installUrl，启动时的「插件源缺失自动补装」无法恢复它，只能重新上传。日志按天落盘，跨天第一次写入时才触发轮转与清理。添加内容源窗口打开时不安装插件，只有点某个扩展的「加载内容源」或工具栏「加载全部仓库内容源」才会安装。
